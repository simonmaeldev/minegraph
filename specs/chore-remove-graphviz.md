# Chore: Remove Graphviz Tests, Scripts, and Everything Related

## Chore Description
Remove all Graphviz-related functionality from the Minegraph project. This includes the Graphviz visualization script, its tests, documentation, configuration files, generated output files, and all references in the README. The project now has newer visualization methods (3D NetworkX and Cosmograph) that don't require Graphviz, making the old 2D Graphviz visualization obsolete. This chore will clean up the codebase and reduce dependencies.

## Relevant Files
Use these files to resolve the chore:

- **src/visualize_graph_with_graphviz.py** - Main Graphviz visualization script that needs to be deleted. This is the core graphviz implementation file.
- **tests/test_visualize_graph.py** - Test file specifically for the Graphviz visualization that needs to be deleted. Contains all unit tests for the graphviz module.
- **pyproject.toml** - Contains the `graphviz>=0.21` dependency that needs to be removed from the dependencies list.
- **README.md** - Contains extensive documentation about Graphviz installation, usage, and features that needs to be removed. Includes CLI examples, command-line options, performance notes, and comparison tables.
- **config/graph_colors.txt** - Color configuration file used by Graphviz visualization. May still be used by other visualizations (3D and Cosmograph), so need to verify before deletion.
- **.claude/commands/conditional_docs.md** - References `app_docs/feature-0-graphviz-visualization.md` that should be removed from the conditional documentation list.
- **specs/feature-graphviz-visualization.md** - Original feature specification document that should be deleted.
- **app_docs/feature-0-graphviz-visualization.md** - Implementation documentation for the Graphviz feature that should be deleted.
- **specs/feature-fzf-interactive-options.md** - Contains a reference to `visualize_graph_with_graphviz.py` in line 215 that needs to be updated or removed.
- **src/__pycache__/visualize_graph_with_graphviz.cpython-313.pyc** - Python cache file that needs to be deleted.

### Generated Output Files
- **output/graphs/transformation_graph.svg** - Generated Graphviz SVG file (may be deleted if only used for graphviz)
- **output/graphs/crafting_only.svg** - Generated filtered Graphviz SVG file (may be deleted if only used for graphviz)
- **output/graphs/custom_graph.svg** - Generated custom Graphviz SVG file (may be deleted if only used for graphviz)
- **output/graphs/multi_format.svg** - Generated multi-format Graphviz SVG file (may be deleted if only used for graphviz)
- **output/graphs/*.png, *.pdf** - Any PNG or PDF files generated by Graphviz (if present)

### Alternative Visualizations
After this chore, users will still have two powerful visualization options:
- **3D Interactive Visualization** (NetworkX + Matplotlib) - No system dependencies required
- **Web-Based Visualization** (Cosmograph) - GPU-accelerated, modern web interface

### System Dependency Removal
After this chore, users will no longer need to install the Graphviz system library (`brew install graphviz`, etc.), simplifying the setup process.
